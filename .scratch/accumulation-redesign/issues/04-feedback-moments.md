# 积累在什么时刻被看见

Type: prototype
Status: resolved
Blocked by: 01, 02

## Question

依据票 02 的实验结果，决定积累在哪些时刻、以什么内容出现：

1. **复习当下**：只在有内容的变化时出现（跨阶段、首次跨过某阈值），平时安静？
2. **停下时（篝火）**：本次新跨阶段的卡（附标题）；是否显示剩余待复习数（倾向不显示）？
3. **面板第一屏**：装备清单（按距离排序）还是按书汇总？

原型：用真实数据生成 2–3 版文案让用户挑。

## Answer

2026-10-16 用户确认并已在 `org-sm.el` 实现：

1. **复习当下**：评分后回显 `旧间隔 → 新间隔`；跨阶段（7/30/90/180）时额外标注 `(🌿 成株 → 🌲 常青)`；dismiss 回显 `已筛选 (计入处理量)`。同时触发 `org-sm-after-review-functions`。
2. **随时停下 / 结束时（篝火小结）**：队列做完或按 `a`（`org-sm-review-abort`）都显示 `🔥 篝火小结 · 本次处理 N 张（复习 X · 已筛选 Y） · 升阶 ...`，**绝不显示剩余到期数**，停下即合法终点。
3. **面板第一屏**：`org-ladder-show-details` 置顶 `📚 知识存量` + `🏺 累计解锁遗迹` + `🏅 永久赛季徽章陈列`。
